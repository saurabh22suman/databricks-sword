# Mission Briefing: Advanced SQL Analytics

## Situation Report

**Client:** StreamVerse Media — a streaming platform with 45 million subscribers and 2 billion viewing events per month.

**Crisis:** Their analytics team writes SQL queries that take 20+ minutes on Gold tables. Root causes: deeply nested subqueries, redundant full table scans, no materialized views. The CTO wants "analytics at the speed of thought."

**Your Mission:** Refactor analytics SQL using advanced patterns: replace subqueries with CTEs, leverage window functions for rankings and running totals, create materialized views, and optimize execution plans.

## Objectives
- Map SQL execution flow: Parse → Optimize → Execute → Cache
- Build a complex analytics query step-by-step using CTEs
- Write advanced SQL: CTEs, window functions, materialized views
- Validate mastery of SQL optimization

## Key Intelligence
- **CTEs:** Named temporary result sets that break complex queries into readable, debuggable steps
- **Window Functions:** ROW_NUMBER(), RANK(), LAG(), LEAD() for rankings, running totals, trend analysis
- **Materialized Views:** Pre-computed results stored as Delta tables, auto-refreshed when base data changes
- **Query Optimization:** EXPLAIN plans, predicate pushdown, Z-ORDER indexing, ANALYZE TABLE for statistics
