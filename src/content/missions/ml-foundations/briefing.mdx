# Mission Briefing: ML Foundations

## Situation Report

You've joined QuantFin Capital, a quantitative hedge fund managing $2.3B in assets. The ML team has a problem: experiment chaos.

Over 6 months, the team trained 427 different models for credit risk prediction, each with different hyperparameters, feature sets, and evaluation metrics. When asked "Which model performed best last month?", it takes 3 days to answer. When a model gets deployed, nobody knows which hyperparameters were used. Reproducibility is impossible.

## Objectives
- Load synthetic user-item rating data
- Track experiments using MLflow (parameters, metrics, artifacts)
- Train an ALS model to predict ratings
- Log results for reproducibility and comparison
- Visualize metrics across multiple runs

## Key Intelligence
- **MLflow:** Open-source platform for managing the ML lifecycle
- **Experiments:** Group related training runs
- **Parameters:** Hyperparameters like learning rate, model rank
- **Metrics:** Accuracy, RMSE, training time
- **Artifacts:** Trained models, plots, data samples

## Success Criteria
- All runs logged with parameters, metrics, and model artifacts
- RMSE < 1.0 on test data
- Experiment UI shows clear comparison of hyperparameter effects
- Model reproducible from logged artifacts
