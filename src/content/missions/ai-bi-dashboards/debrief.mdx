## Key takeaways

| Feature | What it does |
|---|---|
| **Dataset** | A UC table or SQL query bound to the dashboard |
| **Dataset Relationship** | Declared semantic join between datasets; enables cross-filtering |
| **Genie Panel** | Embedded Genie Space for in-dashboard NL Q&A |
| **AI Insight** | LLM-generated summary of a chart's notable patterns |
| **AI Visualization** | Canvas-generated chart from a natural-language request |
| **Cross-filter** | Click a bar in one chart → all related charts filter to that selection |

## Glossary

- **Lakeview** — Databricks' native dashboarding product (the canvas)
- **AI/BI** — Databricks' AI-augmented BI product family (Genie, Dashboards, etc.)
- **Widget** — a single chart/table/text/KPI on the dashboard
- **Page** — a tab in a multi-page dashboard
- **Scheduled refresh** — automatic re-execution of underlying queries on a cron
