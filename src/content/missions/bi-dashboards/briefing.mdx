# Mission Briefing: BI Dashboards

## Situation Report

**Client:** NovaMart — a national retail chain with 800 stores, 12,000 SKUs, and $4.2B annual revenue.

**Crisis:** Their BI team uses legacy Tableau/Power BI dashboards connected to a data warehouse that's 6 hours stale. Store managers make inventory decisions on yesterday's data. The VP of Analytics wants real-time dashboards directly on the Lakehouse with self-service analytics.

**Your Mission:** Build a production BI dashboard system using Databricks SQL: configure SQL Warehouses, create Lakeview dashboards with parameters, set up alerts for KPI breaches, and schedule automated refreshes.

## Objectives
- Map the BI dashboard architecture: SQL Warehouse → Queries → Dashboards → Alerts
- Build the dashboard workflow from data preparation to published dashboard
- Implement dashboard and alert configuration: parameters, visualizations, alerts
- Validate mastery of Databricks BI

## Key Intelligence
- **SQL Warehouses:** Serverless (instant startup, pay-per-query) or Pro (dedicated endpoints, predictive caching)
- **Lakeview Dashboards:** Databricks-native, SQL-backed visualizations with parameters and auto-refresh schedules
- **SQL Alerts:** Schedule queries, trigger on conditions, notify via Slack/email/webhook
