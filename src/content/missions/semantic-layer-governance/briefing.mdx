# Mission Briefing: Semantic Layer & Governance

## Situation Report

**Client:** OmniGroup Holdings — a Fortune 500 conglomerate with 8 business units, 3,000 analysts, and 500+ dashboards.

**Crisis:** Every business unit defines "revenue" differently. Marketing counts gross bookings, Finance counts net after refunds, Operations counts fulfilled orders. When the CEO asks "What's our revenue?", she gets three different answers. The CDO demands a single source of truth with natural language access.

**Your Mission:** Build the semantic layer: governed data products with standard metric definitions, AI/BI Genie for natural language analytics, data contracts to prevent breaking changes, and row-level security.

## Objectives
- Map the semantic layer architecture: Data products → Metric layer → Genie → Consumers
- Build a governed data product from Gold table to published, documented data product
- Implement security and contracts: RLS, column masking, schema contracts
- Validate mastery of enterprise BI governance

## Key Intelligence
- **Data Products:** Curated datasets published in Unity Catalog with metadata, versioned with SLA commitments
- **AI/BI Genie:** Translates plain English to SQL using table metadata and metric definitions, governed by UC permissions
- **Metric Layer:** Company-wide definitions encoded as SQL views, version-controlled with approval requirements
- **Row-Level Security:** Dynamic views filtering data based on user identity — same dashboard, different data
