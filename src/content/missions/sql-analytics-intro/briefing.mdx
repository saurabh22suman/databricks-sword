# Mission Briefing: SQL Analytics Intro

## Situation Report

TechCorp's lakehouse is live. Marketing hired 3 new business analysts who only know SQL (no Python/Spark). They need to query the lakehouse, but traditional SQL tools can't connect to Delta Lake.

Notebooks feel like coding to analysts, cluster management is confusing, and costs are unpredictable ($2,400 last week from a cluster left running overnight).

## Objectives
- Understand SQL Warehouse architecture (clusters, endpoints, catalogs)
- Write multi-table JOIN queries
- Aggregate data with GROUP BY and window functions
- Create views for reusable query logic
- Compare SQL vs PySpark for different use cases

## Key Intelligence
- **Serverless SQL Warehouses:** Default compute for SQL workloads — instant-on, auto-scaling, zero infrastructure management
- **BI tool integration:** Connect Tableau, Power BI, Looker directly to the lakehouse
- **Query editor:** Familiar SQL interface with intelligent autocomplete
- **Cost optimization:** Automatic scale-to-zero, Photon acceleration, query result caching

## Success Criteria
- Working SQL queries with JOINs and aggregations
- View created for customer metrics
- Performance optimized with proper JOIN order
- Tradeoff understanding (when SQL, when PySpark)
